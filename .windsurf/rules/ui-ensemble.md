# UI Ensemble (Windsurf / Cascade)

When doing UI or visual work:

1. Load and follow **pen-design** (pen.dev CLI) for mockups/exports when a visual is useful.
2. Also use other available UI skills together: `ui-ensemble`, `ui-ux-pro-max`, `design`, `design-system`, `ui-styling`, `design-taste-frontend`, `frontend-design`, `brand`, `slides`, `banner-design`.
3. pen.dev is additive — do not skip taste/system/styling skills after generating a mockup.
4. Pass the user's wording verbatim to `pen --prompt`; do not invent a competing design brief in the CLI prompt.
